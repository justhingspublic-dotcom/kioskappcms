# KioskAdmin 進度文件

> 最後更新：2026-09-02｜狀態：**基礎功能完成，進入視覺設計調整階段**

## 這是什麼

Kiosk 展示機的雲端管理後台。定位：**把 KioskApp 現有功能照搬到網頁上做遠端控制**——App 的行為是標準答案，網頁的預覽與操作邏輯都以「跟手機上一模一樣」為驗收準則。

```
瀏覽器（管理網頁）──┐
                    ├─→ Node/Express API ─→ 公司 SQL Server（192.168.1.92）
Kiosk 機器（App）──┘         │
                          uploads/（圖片影片檔，DB 存路徑）
```

## 已完成 ✅

### 伺服器（src/）
- Express API + 公司 MSSQL（啟動自動建 `KioskAdmin` 資料庫與資料表）
- 設定以整份 JSON 儲存（格式同 App 的 LayoutTree 序列化），每次發布版本 +1
- **長輪詢 `/wait`**：機器掛著等，網頁一發布立刻喚醒 → 秒級同步
- 檔案上傳（網頁登入者或機器金鑰皆可，上限 500MB，UUID 檔名）
- 會員系統：帳號（scrypt 雜湊）、管理員可開帳號並把機器分配給帳號、一般帳號只看得到自己的機器（403 隔離已實測）
- 網頁儲存**不覆蓋展示頁**：不帶 activePage 時伺服器沿用舊值（機器不會被踢回第一頁）

### 管理網頁（public/）
- 視覺化編輯器，操作邏輯 = App：真實螢幕比例畫布（機器上報解析度）、拖分隔線調大小（右上角實際像素角標即時跳動）、點格子右側面板逐格設定
- 版面結構：上下/左右分割、合併、大區塊增刪（max 3）、頁面增刪改名（max 8）、「在機器上展示此頁」
- 每格設定：背景（純色色票/輪播圖/天氣格多「天氣背景」三選一）、內容六種（跑馬燈速度、文字、天氣地區、網頁、影片）、文字色、點擊動作
- **預覽擬真**（規則照抄 App 原始碼）：跑馬燈字高=格高 55% 等速滑動、圖片多張輪播 600ms 淡接、天氣抓真實資料（Open-Meteo，同 App 的 API 與天空配色表）、Material Icons、尺寸角標同 App CellChip
- 上傳圖片尺寸不符警告（同 App 文案）；機器發布新版時網頁 5 秒內自動載入
- 帳號管理面板（開帳號、刪帳號、機器分配）

### App 端（KioskApp repo，commit e77010a）
- 雲端同步（設定頁，**預設關閉**，關閉時 App 行為與純本機版完全相同——這是鐵則）
- 掛 `/wait` 秒級接收發布；本機修改 1.2 秒防抖自動上傳；「立即同步」按鈕
- 媒體雙向：伺服器圖片全數下載快取後才套用（斷網不破圖）；**手機本機選的圖自動上傳**改寫為伺服器路徑
- 上報螢幕解析度；管理預覽鎖定螢幕滿版比例（裁切與實機/網頁一致）

## 如何啟動

```bash
cd c:\Code\KioskAdmin
npm start          # http://localhost:3000（區網：http://192.168.1.142:3000）
```
登入：`admin` / 見 `.env` 的 ADMIN_PASSWORD。機器端金鑰：`.env` 的 DEVICE_KEY。
`.env` 不進 git；新環境照 `.env.example` 填。API 規格見根目錄 `API.md`。
