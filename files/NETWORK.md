# 網路連線限制盤點（內網 vs 外網）

> 最後更新：2026-09-03｜結論：**整套目前只能在公司內網跑；要對外，只需打通 Node 伺服器那一台，程式幾乎不用改。**

## 連線關係圖

```
瀏覽器（管理網頁）──┐
                    ├─→ Node/Express API（192.168.1.142:3000）─→ 公司 MSSQL（192.168.1.92）
Kiosk 機器（App）──┘         │
                          uploads/（圖片影片，DB 只存路徑）
```

- Express 有聽所有網卡（不是只有 localhost），同網段裝置都連得到。
- App 端伺服器網址是設定頁填的、沒有寫死（`CloudSyncConfig.kt`），要換對外網址只是改設定。
- 網頁前端由同一台 Express 服務（同源，未開 CORS）。

## 外網連不到的（都綁在內網）

| 東西 | 位置 | 說明 |
|---|---|---|
| Node API 伺服器 | 開發機 `192.168.1.142:3000` | 內網 IP，防火牆外沒有路進來 |
| 管理網頁 | 同一台 Node 服務 | 跟著伺服器一起通/不通 |
| 上傳檔案（uploads/ → `/files/...`） | 同一台 Node | 同上 |
| 公司 MSSQL | `192.168.1.92` | 只有 Node 需要連它；kiosk 與網頁都不直連 DB。**不需要也不應該對外** |

### 自家 API 全部在同一台上（一起通或一起不通）

`src/server.js` 的所有端點命運相同，沒有「部分通」的情況：

- 登入/帳號：`/api/login`、`/api/me`、`/api/users`
- 機器管理：`/api/devices`（清單/分配擁有者/刪除）
- 設定同步：`/api/config/:deviceId`、`/version`、`/wait`（長輪詢）
- 共用設定：`/api/shared-settings`（聊天帳號、睡眠排程）
- 檔案：`/api/upload`、`/files/...`
- JustAI 代理：`/api/justai/agents`（伺服器「往外」問 JustAI 沒問題；卡的是外面連不進伺服器）

## 外網連得到的（kiosk 擺出去照常運作）

- JustAI 聊天本體（App 直連公網服務，不經過自家伺服器）
- Open-Meteo 天氣
- 格子設定的網頁、YouTube 影片等公網內容

## kiosk 擺到外網會發生什麼

唯一斷的是**雲端同步**這一條：收不到管理網頁發布的新版面、抓不到伺服器上的新圖片。
其他功能（聊天、天氣、跑馬燈、已下載快取的圖片、網頁/影片內容）不受影響，App 照最後一次同步到的設定繼續跑（雲端同步預設關閉時更是與純本機版完全相同）。

## 對外的兩條路

1. **正規做法**：公司提供對外伺服器或固定 IP + port forwarding，Node 搬過去（該台需連得到 `192.168.1.92` 的 MSSQL）；App 與網頁改填對外網址即可。屬網管作業，非程式改動。
2. **快速測試**：開發機跑 Cloudflare Tunnel / ngrok，把 `localhost:3000` 映射成公網網址（自帶 HTTPS、不動公司防火牆）。

### 對外前要一併處理

- **HTTPS**：目前純 http，帳密與機器金鑰都在傳；Android 對 cleartext http 也有限制。
- **GitHub Pages 行不通**：它只放靜態檔，解決不了 API 在內網的問題；且 HTTPS 頁面打 http API 會被瀏覽器以 mixed content 擋下，跨網域還需另開 CORS。網頁本來就跟著 Express 走，伺服器對外了網頁自然對外。
- 資安整理：DB 改用非 sa 帳號、`.env` 密碼更換、伺服器常駐化（pm2 等）。
